# AI Tools Explorer 🚀

A modern, responsive web application designed to discover, search, rate, and explore the best artificial intelligence websites and tools. Powered by the live **freeserp.ai API** and featuring full multi-language support (English, Arabic, and Ukrainian).

## ✨ Features

* **Live AI Data Search:** Fetch real-time AI tools directly via the `freeserp.ai` public API.
* **Multi-Language Support:** Seamlessly switch between English, Arabic (with RTL alignment), and Ukrainian.
* **Favorites System:** Save your preferred AI tools locally using `localStorage`.
* **Custom Tool Submission:** Add your own custom AI websites to the platform.
* **Interactive Ratings & Previews:** Rate tools with a star system and get quick pop-up previews of any tool.
* **Modern UI/UX:** Built with Tailwind CSS, custom CSS styles, and FontAwesome icons, featuring a sleek dark mode interface.

---

## 🛠️ Tech Stack

* **HTML5 / CSS3** (`style.css`)
* **Tailwind CSS** (via CDN)
* **Vanilla JavaScript** (ES6+)
* **FontAwesome** (Icons)
* **Freeserp.ai API** (Backend data source)

To run this project locally, simply follow these steps:

    1- Clone or download this repository to your local machine.
    2- Open the project folder.
